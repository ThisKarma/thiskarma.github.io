# Сайт с тактиками CS2

Кидаете PDF с тактикой в папку `tactics/`, и через несколько секунд она появляется на сайте. Тактика сама попадает в нужный раздел: карта → команда → тип.

## Установка (один раз)

1. **Python 3.10+**: https://www.python.org/downloads/ (на Windows при установке отметьте галочку *Add Python to PATH*).
2. **Tesseract OCR** нужен, чтобы распознавать текст: в PDF текст сохранён картинкой.
   - Windows: `start.bat` сам поставит его через winget, достаточно согласиться на установку. Если не получилось, возьмите установщик со страницы https://github.com/UB-Mannheim/tesseract/wiki. Ставьте в папку по умолчанию. Русский язык выбирать не нужно, он уже лежит в `engine/tessdata`.
   - macOS: `brew install tesseract`
   - Linux: `sudo apt install tesseract-ocr`
3. Библиотеки Python установятся сами при первом запуске. Вручную: `pip install -r requirements.txt`.

## Запуск

- **Windows**: двойной клик по `start.bat`
- **macOS / Linux**: `./start.sh`, или `python3 start.py`

Сайт откроется в браузере по адресу http://localhost:8000. Пока окно запуска открыто, программа следит за папкой `tactics/`:

| Что сделали | Что произойдёт |
|---|---|
| положили новый PDF | тактика распознаётся и появляется на сайте |
| заменили PDF | тактика обновится |
| удалили PDF | тактика пропадёт с сайта |

Открытые вкладки перезагружаются сами. Одинаковые файлы (например, «… (2).pdf») показываются один раз. Если Tesseract ещё не установлен, тактика всё равно появится: с картинками, оригиналом и разделом по имени файла. Текст распознается автоматически при следующем запуске после установки Tesseract. Первое распознавание занимает около 10 секунд на тактику. Результат кэшируется в `.cache/`, поэтому при следующих запусках всё мгновенно.

## Как тактика попадает в нужный раздел

Программа читает **имя файла** и **заголовок PDF** (первая крупная строка на первой странице):

- если они совпадают, или карта/команда указана только в одном из них, берётся то, что найдено;
- если они противоречат друг другу, побеждает **имя файла**.

Поэтому достаточно называть файлы примерно так:

```
Фуллбай от FUT на даст 2.pdf
Раш Б от Falcons на анубисе.pdf
Медленный сплит А от Vitality на мираже.pdf
```

Можно раскладывать PDF и по подпапкам, например `tactics/Anubis/Falcons/раш.pdf`. Имена папок тоже учитываются.

Что распознаётся:
- **карты**: Dust 2, Mirage, Inferno, Nuke, Ancient, Anubis, Train, Overpass, Vertigo, Cache (по-русски и по-английски: «даст 2», «мираж», «анубис»…). Тактика без карты попадёт в «Другие карты»;
- **команды**: Spirit, Falcons, Vitality, FUT, NAVI, FaZe, G2, MOUZ, MongolZ, Aurora и ещё около 25 команд. Неизвестную команду программа возьмёт из фразы «от ХХХ». Если команды нет совсем, тактика попадёт в «Без команды»;
- **тип**: Пистолетка, Эко, Форс, Раш, Сплит, Фуллбай, Дефолт, Кол, плюс метки «Плент A/B», «Через шорт», «Люрк» и т.п.

Добавить карту, команду или тип можно в файле `engine/classify.py` (простые списки в начале файла).

## Что на странице тактики

- Заголовок, подзаголовок из скобок и «Суть тактики» вынесены в шапку.
- Текст распознан и свёрстан: шаги с номерами, списки, блоки «‼️ Ключ к успеху» и «⚠️ Главное».
- Блок «Закуп» из зелёной рамки показан отдельной карточкой сбоку.
- Скриншоты раскидов и миникарты вырезаны из PDF и стоят рядом со своими подписями. По клику открываются на весь экран, листаются стрелками или свайпом.
- Внизу оригинальные страницы PDF 1 в 1 и кнопка «Скачать PDF». Если распознавание где-то ошиблось, оригинал всегда под рукой.

## Перенос на сервер

Вариант 1: только готовый сайт. Выполните `python start.py --build` и загрузите папку `site/` на любой хостинг статических файлов (nginx, Apache, GitHub Pages, Netlify). После добавления новых PDF повторите.

Вариант 2: автообновление прямо на сервере. Скопируйте всю папку проекта, установите Python и Tesseract и запустите:

```
python3 start.py --host 0.0.0.0 --port 8000 --no-browser
```

Теперь достаточно закидывать PDF в `tactics/` на сервере. Для постоянной работы оформите запуск как службу (systemd) или поставьте nginx перед ним.

## Структура

```
tactics/          ← сюда кладёте PDF
site/             ← готовый сайт (генерируется, руками не править)
.cache/           ← кэш распознавания
engine/
  parse_pdf.py    ← разбор PDF: картинки, текст, блок «Закуп»
  classify.py     ← карта / команда / тип
  build.py        ← генерация страниц
  assets/         ← стили и скрипты сайта
  tessdata/       ← модели распознавания (рус/англ)
start.py          ← запуск и слежение за папкой
```
